# `bdc/` — BDC universe registry

This directory holds the canonical list of Business Development
Companies PriCredit tracks, plus the EDGAR response cache.

| Path | Tracked in git | Purpose |
|------|---------------|---------|
| `bdc_universe.json` | no | Generated by `scripts/discover_bdcs.py`. Schema: `{as_of, source, counts, bdcs[]}`. |
| `bdc_overrides.json` | (future) yes | Manual adjustments: force-include / force-exclude specific CIKs, set preferred tickers, curate peer groups. |
| `company_tickers.json` | no | Local copy of `https://www.sec.gov/files/company_tickers.json` when cached. |
| `_cache/` | no | EDGAR response cache. Safe to delete at any time. |

Build / refresh:

```bash
scripts/discover_bdcs.py --out bdc/bdc_universe.json
```

Inspect:

```bash
jq '.counts' bdc/bdc_universe.json
jq '.bdcs[] | select(.primary_ticker=="ARCC")' bdc/bdc_universe.json
```
